# Component selection

Choose by task, focus, timing, and recovery.

| Need | Choose | Reject when |
|---|---|---|
| One short submitted value | Select | Filtering is needed or context changes |
| Filter a large predefined set | Combobox | Free-form text is valid |
| Change workspace or environment | Context Switcher | It is an ordinary form field |
| Compare a few visible form choices | Radio Group | The set is long or space is constrained |
| Switch immediate peer modes | Segmented Control | Options need descriptions or submit later |
| Compact anchored actions | Menu | Search or cross-product discovery is needed |
| Search and run many actions | Action List | The set is a short anchored menu |
| Keep a few controls by their origin | Popover | The task needs trapped focus or a long form |
| Complete a focused cancellable task | Dialog | A consequential response is required |
| Confirm an irreversible decision | Alert Dialog | A reliable Undo path exists |
| Brief non-blocking outcome | Toast | The user must respond or status must persist |
| Recover a reliable mutation | Undo Stack | The inverse is unsafe or lossy |
| Inspect one item without losing place | Shared Detail | The detail is an independent destination |
| Compare and operate on a collection | Data Table | A short static table is enough |
| Inspect ordered analytic values | Chart | Only direction matters or categories are unordered |

Do not merge components because their closed shapes look similar.
