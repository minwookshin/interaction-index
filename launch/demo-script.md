# Teum release-candidate demo

Target: 75–90 seconds, one continuous capture, 1280 × 720, light theme first.

## 0–12 seconds — What it is

Open the landing page. Hold long enough to read the headline and pinned install command.

Voiceover: “Teum is an open-source React component and interaction system for compact product workflows. Components are the baseline; state change is the product.”

## 12–30 seconds — Source-owned component

Open Documentation, navigate to Button, and show Product, one state inspection, collapsed code, Accessibility, and API without racing the scroll.

Voiceover: “Every component documents a real composition, only distinct states, keyboard and reduced-motion behavior, generated TypeScript API, and the source that enters your product.”

## 30–56 seconds — Signature behavior

Open the Preserve context Playground. Select a second item, open its Shared Detail surface, complete the task, then use Undo Stack.

Voiceover: “Shared Detail preserves spatial context. Action List finds the work. Undo Stack makes the mutation recoverable. The geometry explains what changed without making keyboard work wait for motion.”

## 56–72 seconds — Product proof

Open Product pilot. Search, create an issue, inspect it, archive it, then undo. Keep the pointer still after each transition so the motion remains legible.

Voiceover: “The issue workspace is an internal API proof, not an adoption claim. It composes the same public components into one executable task.”

## 72–90 seconds — Honest handoff

Return to Installation, show the exact `rc.8` command, then end on GitHub.

Voiceover: “The pinned registry is ready to evaluate. The npm package is not published, APIs may still change, and external adoption and device evidence remain open. Try one real component and tell me where the system stops helping.”

## Capture checks

- No staged toast, menu, tooltip, or focus ring is already open at a scene boundary.
- Keyboard focus is shown only after keyboard input.
- No private browser chrome, account name, token, local path, or notification is visible.
- The live site, registry version, release notes, and spoken status all match.
- Export one captioned version and one clean version; do not use autoplay audio as the only explanation.
