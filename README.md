# Teum

React and TypeScript components for product interfaces.

> Teum is currently in pre-release. APIs may change.

## Install

```bash
npx shadcn@4.18.0 registry add \
  @teum-pinned=https://teum.minwookshin.com/r/v/0.1.0-rc.25/{name}.json

npx shadcn@4.18.0 add @teum-pinned/button
```

Read the [documentation](https://teum.minwookshin.com) for components, accessibility, and API details.

## Development

```bash
npm install
npm run dev
npm test
```
