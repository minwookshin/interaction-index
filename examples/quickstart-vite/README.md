# whatiuse + Vite quickstart

This is the exact plain-CSS starter exercised by `npm run test:adoption:vite`. The verifier copies it to a clean directory, connects the pinned whatiuse registry, installs Button, and requires React 18 and React 19 type checks and production builds.

The `--whatiuse-radius-control` override is intentional. It proves that product CSS can customize the semantic contract without editing generated component CSS.
