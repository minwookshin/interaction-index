# Teum 0.1.0-rc.18

Date: 2026-08-16
Status: local release candidate; npm unpublished; not promoted to the public site

## Product Patterns v1

This candidate adds three complete B2B product tasks:

- Customer Workspace
- Billing & Usage
- Members & Permissions

Each pattern composes the existing Teum Core, Data, and Analytics layers. Shared contracts define task sequence, state ownership, invariants, failure handling, keyboard behavior, and reduced-motion behavior so adopters and coding agents can understand why the composition is structured that way.

`rc.18` supersedes the rejected `rc.17` preview by adding the missing accessible name for the invoice action column found during Storybook review.

## Install for local evaluation

```bash
npx shadcn@4.18.0 registry add @teum-pinned=https://teum.minwookshin.com/r/v/0.1.0-rc.18/{name}.json
npx shadcn@4.18.0 add @teum-pinned/teum-product-patterns
```

The 45-component Core catalog and 15 product primitives remain unchanged. The three patterns are locally tested reference implementations, not external production-adoption evidence. Publication and deployment remain separate maintainer decisions.
