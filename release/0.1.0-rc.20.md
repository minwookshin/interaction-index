# Teum 0.1.0-rc.20

Status: local release candidate; unpublished and not deployed

## Added

- Executable Vite and Next.js App Router quickstarts.
- Theme integration, reviewed update, migration, and troubleshooting guidance.
- Machine-readable Adoption DX evidence for four clean-consumer journeys.

## Verified locally

- Vite with React 18: registry install, semantic token override, theme switch, strict typecheck, and production build in 8.0 seconds.
- Vite with React 19: the same path plus the optional Tailwind CSS v4 bridge in 10.1 seconds.
- Next.js 16.3.1 App Router: pinned install, one explicit client boundary, theme integration, strict typecheck, and production build in 13.7 seconds.
- Registry update from `rc.19`: non-writing dry-run and diff, explicit acceptance, typecheck, and production build in 14.4 seconds.

## Still not claimed

- independent first-time-user timing;
- npm publication or deployment;
- production adoption or automatic source merging.
