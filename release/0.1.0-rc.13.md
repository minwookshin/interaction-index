# Teum 0.1.0-rc.13

Status: unpublished release candidate under local verification on 2026-08-16.

## Teum Data v1

- Data Table
- Filter Builder
- Data Toolbar
- Bulk Action Bar
- Date Range Filter
- Data Export Menu
- versioned view-state and export helpers
- Issues Workspace, Customer Directory, and Audit Log recipes
- Motion Contract v1
- agent-readable component and recipe contracts

The 45-component Core catalog is unchanged. Teum Data is an additive product layer with six public product-component modules and three installable compositions.

## Install

```bash
npx shadcn@4.18.0 registry add @teum-pinned=https://teum.minwookshin.com/r/v/0.1.0-rc.13/{name}.json
npx shadcn@4.18.0 add @teum-pinned/teum-data
```

Acceptance requires a fresh React + TypeScript + Vite install, React 18 and 19 package consumers, exact public API and registry verification, and light/dark accessibility and browser coverage.

## External gates

- independent adoption;
- physical-device and Edge review;
- independent accessibility review;
- maintainer-approved tag or publication.

Automated checks do not close these gates.
