# Teum 0.1.0-rc.21

Status: local release candidate; unpublished and not deployed

## Hardened

- Pins every GitHub Action to a reviewed commit and prevents checkout credentials from persisting.
- Separates read-only builds from Pages deployment and package-attestation credentials.
- Builds package and release candidates in fresh staging directories with exact allowlists and atomic output replacement.
- Verifies immutable registry history and shared hosting security headers.
- Runs clean-room verification in an isolated no-hardlinks Git clone instead of sharing the owner's Git metadata with nested fixtures.

## Verified locally

- 203 source tests and 102 Storybook interaction contracts.
- 295 applicable browser checks passed, with 350 intentional project-ownership skips and no failures or flakes.
- 55 applicable accessibility checks passed across ten required contracts, with 30 intentional skips and no failures or flakes.
- 69 public routes and 330 reviewed light/dark visual baselines on macOS.
- React 18, React 19, and Next.js clean consumers; explicit source-update review; package SSR and hydration; Core, Data, Analytics, Product Patterns, and Agent clean installs.
- Route-aware bundle budgets and local production-preview interaction budgets.
- Zero known high-severity npm audit findings in the verified lockfile.
