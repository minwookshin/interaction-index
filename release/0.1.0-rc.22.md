# Teum 0.1.0-rc.22

Status: public-beta candidate; unpublished until the tag, prerelease, site, and registry pass live verification

## Added

- A public-beta evidence ledger with separate publication and v1 promotion gates.
- An isolated npm tarball assembler, dry-run verifier, checksums, and SBOM handoff.
- A stage-only npm trusted-publishing workflow that does not use a long-lived token.
- A live verifier for the canonical site, exact immutable registry bytes, GitHub prerelease, npm record, cache policy, and security headers.
- A tag-pinned GitHub registry quickstart for the pre-npm beta.

## Verified locally

- The complete source, Storybook, visual, registry, clean-consumer, package, Sites, and performance gates.
- A publishable tarball assembled separately from the private repository package.
- GitHub, site, registry, npm, and v1 evidence remain independently gated; missing evidence is reported as open rather than inferred.

## Still not claimed

- npm publication or successful independent installation;
- two completed external feedback rounds;
- the 28-day stable API window;
- Windows Edge, physical-device, independent accessibility, human translation/RTL, or complete Linux visual review;
- v1 readiness or production adoption.
