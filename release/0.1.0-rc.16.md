# Teum 0.1.0-rc.16

Date: 2026-08-16
Status: local release candidate; npm unpublished; not promoted to the public site

## Teum Analytics v1

This candidate adds nine product-level analytics components:

- Sparkline, Metric, Chart, Comparison, Breakdown
- Goal, Funnel, Cohort, Timeline

It also adds three working recipes:

- SaaS Overview
- Product Usage
- Conversion & Retention

The recipes share exact-value inspection, keyboard navigation, reduced-motion behavior, responsive overflow handling, semantic table fallbacks, and agent-readable composition contracts. Teum's native SVG implementation adds no chart runtime dependency.

## Install for local evaluation

```bash
npx shadcn@4.18.0 registry add @teum-pinned=https://teum.minwookshin.com/r/v/0.1.0-rc.16/{name}.json
npx shadcn@4.18.0 add @teum-pinned/teum-analytics
```

The 45-component Core catalog remains unchanged. Teum now exposes 15 additive product components across Data and Analytics. Local verification does not establish external adoption, physical-device coverage, or production performance. Publication and deployment remain separate maintainer decisions.
