# Teum 0.1.0-rc.14

Status: locally verified, unpublished release candidate on 2026-08-16.

- Data Table
- Filter Builder
- Data Toolbar
- Bulk Action Bar
- Date Range Filter
- Data Export Menu

- Issues Workspace, Customer Directory, and Audit Log recipes

## Install

```bash
npx shadcn@4.18.0 registry add @teum-pinned=https://teum.minwookshin.com/r/v/0.1.0-rc.14/{name}.json
npx shadcn@4.18.0 add @teum-pinned/teum-data
```
