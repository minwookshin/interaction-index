# Teum 0.1.0-rc.23

Status: local release candidate; unpublished and undeployed

## Added

- Donut Chart and Heatmap as additive Analytics components.
- Line, area, bar, and stacked-bar rendering through the shared Chart contract.
- A responsive component catalog containing a live square preview for each of the 45 Core components.

## Refined

- Quieter collection navigation and documentation hierarchy.
- Stable preview geometry across light, dark, desktop, and compact layouts.
- Keyboard, reduced-motion, error, empty, and loading coverage for the expanded Analytics surfaces.

## Local acceptance boundary

- 210 unit tests, 104 Storybook interaction checks, 323 applicable browser checks, and 332 visual baselines pass for this candidate.
- React 18, React 19, Next.js, registry upgrade, package SSR/hydration, accessibility, Sites, and local runtime-performance evidence pass.

- The npm package remains private.
- No Vercel deployment, domain mutation, GitHub release, tag, or npm publication is authorized for this candidate.
- The live `0.1.0-rc.22` site and registry evidence remain historical and are not evidence for `0.1.0-rc.23`.
- External adoption, device review, and production use remain unclaimed.
