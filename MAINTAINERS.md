# Maintainers

## Ownership

Minwook Shin is the current design, API, documentation, registry, and release owner for Teum.

## Triage

- Reproducible defects, documentation gaps, and component proposals use the repository templates.
- Vulnerabilities use a private repository security advisory, never a public issue.
- The maintainer labels compatibility, accessibility, breaking-change, and migration impact before merge.
- Response times are best effort during alpha. No service-level agreement is promised.

## Release authority

Only the maintainer may create a version tag, publish a GitHub Release, remove `private: true`, or publish a registry/package endpoint. Automation verifies candidates but cannot publish them.

Additional maintainers must be named here with their decision scope before receiving release authority.
